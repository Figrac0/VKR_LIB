# 🧩 SPA UI Library

A lightweight, modular JavaScript library for building Single Page Applications (SPA) without relying on external frameworks or bundlers.  
The library was designed to be simple, flexible, and fast to integrate into any project, making it suitable for prototypes, educational projects, and production-ready web applications.


## 🚀 Features

- Dynamic routing without page reloads
- Built-in admin panel 
- Centralized state management (store)
- UI components: modal, datepicker, carousel, tabs, toast, etc.
- Built-in admin panel (via iframe)
- LocalStorage/sessionStorage utilities
- Optimized for small and medium-sized web projects
- Lightweight architecture, no external dependencies
- Cross-browser support(Chrome, Firefox, Edge, Safari)

## 🔧 Tech Stack

- **JavaScript (ES6+)** — core logic and modules  
- **SASS/SCSS** — modular styles, theming, and responsive design  
- **Node.js + Gulp** — build automation (optional)  
- **No external dependencies** — works out of the box with a single `<script>`
-  **PHP** — server-side logic for the admin panel   

  ## 📚 Documentation

- Example usage can be found in the `/examples/` directory.  
- Detailed user guide is available in *Appendix A* of the diploma project.  
- Each module (router, store, UI components) is documented with inline comments.
